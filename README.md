#  Week 3 Pair Programming

## 📌 Project Overview

This repository contains the work completed during Week 3 of the IYF Season 12 Web Foundations course. The project focuses on pair programming, collaboration using Git and GitHub, and practising HTML development.

## 🎯 Objectives

* Practice pair programming and teamwork.
* Improve HTML coding skills.
* Learn how to use Git branches for collaborative development.
* Create and merge pull requests on GitHub.
* Understand how to manage project files using Git and GitHub.

## 🛠️ Technologies Used

* **HTML5** – For structuring web pages.
* **Git** – For version control.
* **GitHub** – For hosting the repository and collaborating.
* **Visual Studio Code** – For writing and editing code.

## 🤝 Pair Programming and Collaboration

This project involved collaborative development using Git and GitHub. The workflow included:

1. Creating and working on a feature branch.
2. Making changes to the project files.
3. Committing and pushing changes to GitHub.
4. Creating a pull request for review.
5. Merging the pull request into the main branch.

## 📚 Key Learnings

* Writing and organising HTML code.
* Understanding Git branches and commits.
* Creating and merging pull requests.
* Collaborating with another developer.
* Managing project files using GitHub.

## 🚀 Getting Started

To view the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/michael-yugi/iyf-s12-week-03-pair-michaelyugi.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.
